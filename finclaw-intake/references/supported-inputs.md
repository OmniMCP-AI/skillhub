# Supported Inputs

Supported now:

- `.xlsx`
- `.xlsm`
- `.csv`
- `.tsv`
- text-based `.pdf`
- `.docx`
- `.zip` bundles containing supported files

Delegated or conditional:

- scanned PDF
- image scans
- legacy `.xls`

Intake should label unsupported or delegated formats explicitly instead of pretending they were parsed.
