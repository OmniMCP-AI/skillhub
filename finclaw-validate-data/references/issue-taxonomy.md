# Issue Taxonomy

Use a simple severity model:

- `blocking_error`
  The workflow should not continue until resolved.
- `warning`
  The workflow may continue, but the issue must remain visible.
- `info`
  Useful note with no delivery impact.

Common issue types:

- missing_source
- unreadable_source
- period_mismatch
- unit_mismatch
- mapping_gap
- statement_inconsistency
- metric_inconsistency
- unsupported_format
