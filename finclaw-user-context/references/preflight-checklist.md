# Preflight Checklist

Before formal finance work starts, check:

1. Is the company or entity scope known?
2. Is the requested period known?
3. Are source files or source systems available?
4. Is there a preferred source of truth?
5. Is there a known template or output mode preference?
6. Are there blocking missing requirements such as permissions or absent files?

If any blocking item fails, return the missing requirement instead of entering deep analysis.
