# Context Schema

Recommended fields:

- `company_name`
- `entity_scope`
- `fiscal_calendar`
- `chart_of_accounts_conventions`
- `preferred_source_order`
- `preferred_report_templates`
- `preferred_delivery_modes`
- `known_metric_defs`
- `last_confirmed_period_scope`
- `readiness_status`

Keep fields factual and reusable. Avoid storing one-off reasoning.
