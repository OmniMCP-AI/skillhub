# Route Types

Use these route types consistently:

- `intake`
  File upload, folder path, unreadable source, unknown source format.
- `formal_report`
  Boss-review report, 财报分析, 经营分析, 管理分析, 审核报告.
- `diagnostic`
  Why a metric changed, where a mismatch came from, what is inconsistent.
- `validation`
  Source checks, unit checks, mapping checks, period checks, completeness checks.
- `dashboard`
  KPI overview, chart page, management dashboard, dashboard refresh.
- `simulation`
  Scenario planning, sensitivity analysis, assumption-driven output.
- `followup_qa`
  Follow-up questions on an existing report or workbook.

Prefer one primary route type. Add supporting skills instead of creating multi-primary routes.
