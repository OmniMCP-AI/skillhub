# 三表解析与老板报告生成复盘：编码异常与列识别

适用场景：客户数据包中存在中文文件名 mojibake、同一公司/母公司重复报表、标准三表脚本能识别公司和报表类型但期间为 UNKNOWN，仍需生成老板审阅版 9-Sheet 报告。

## 关键做法

1. 期间识别不要只依赖文件名。
   - 优先读取 workbook 的首个 Sheet 名和表内日期。
   - 常见映射：`资产负债表2025年3期/6期/9期/12期` → Q1/Q2/Q3/Q4。
   - 常见映射：`利润表2025年第1季度`、`现金流量表2025年1季度`、`现金流量表2025年Q1` → Q1。
   - 若文件名 mojibake 但仍保留 `Q1/Q2/Q3/Q4`，可作为补充信号，不作为唯一依据。

2. 明确报表口径，避免重复报表混入。
   - 数据包可能同时包含本体经营分析目录、母公司副本、子公司单体或合并资料。
   - 先按用户目标公司和目录语义选择本体三表；排除 `母公司`、其他公司名或合并包中的重复三表，除非用户明确要求集团/合并口径。
   - 发现重复报表时，在限制事项或资料清单中披露，而不是混合计算。

3. 利润表/现金流量表取数列要按表头定位。
   - 不要取“项目”右侧第一个数字，因为该列常常是 `行次`。
   - 表头含 `本期金额` 时，季度分析优先取 `本期金额`。
   - 表头含 `本年累计金额` 且无本期列或确认为累计口径时，再按 Q1、Q2-Q1、Q3-Q2、Q4-Q3 转单季。
   - 兼容别名：`研究费用` 应映射到 `研发费用`。

4. 资产负债表关键项要做中文别名兼容。
   - `所有者权益（或股东权益）合计`、`所有者权益(或股东权益)合计` 都应映射到 `所有者权益合计`。
   - 可额外读取 `负债和所有者权益（或股东权益）总计` 用于交叉校验。
   - 必须复核 `资产总计 = 负债合计 + 所有者权益合计`，差异为 0 或在阈值内才通过。

5. MaybeAI 上传后必须回读代表页签。
   - `list_worksheets` 的 `row_count/column_count` 可能为 0，不代表上传失败。
   - 以 `read_sheet` 的 `shape`、`headers`、样例行验证封面、老板摘要、利润分析、现金流分析、数据与计算审核报告。
   - 9 个前台页签必须按模板表头完全匹配；每个数据行必须有管理说明/观察/判断/建议。

## 输出要求

- 报告封面需披露：公司、期间、单位、数据口径、核心结论、限制事项。
- 若经营、预算、合并资料已发现但未逐笔穿透，应写入封面、经营概览、风险与建议、追问支持。
- 交付前至少完成：本地 workbook 回读、三表勾稽、MaybeAI 上传回读（若上传成功）。
