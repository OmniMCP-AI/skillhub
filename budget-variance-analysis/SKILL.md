# 预算管控差异分析

根据用户提供的预算表格和实际数据，自动生成实际数 vs 预算数分项明细对比，识别异常变动并分析差异原因。

## 工作流

### Step 1. 收集输入

确认用户提供以下材料：
- **预算表格**：Excel格式，含各科目/项目的预算金额
- **实际数据**：Excel/CSV格式，含同期实际发生额
- **分析维度**：按科目 / 部门 / 项目 / 期间
- **分析周期**：月度 / 季度 / 年度
- **异常阈值**：差异率超过多少视为异常（默认 ±10%）
- **输出格式**：Excel / Word / PDF（默认 Excel）

若用户将预算和实际数据合并在同一文件中，直接解析。

### Step 2. 解析预算表

读取预算表格，识别：
1. **科目体系**：预算科目层级（收入/成本/费用/资本支出等）
2. **维度结构**：按部门/产品线/项目等维度的预算分配
3. **期间分布**：年度预算的月度/季度拆分
4. **预算金额列**：定位预算数所在列
5. **科目关系**：上下级科目汇总关系（如：管理费用 = 薪酬 + 办公费 + 差旅费 + ...）

常见预算表结构：
- 一级科目 → 二级科目 → 预算金额
- 科目/部门矩阵：行=科目，列=部门

### Step 3. 解析实际数据

读取实际数据文件，识别：
1. **科目映射**：实际科目与预算科目的对应关系
2. **期间数据**：各月度/季度实际发生额
3. **累计数据**：本年累计实际数
4. **维度匹配**：实际数据的维度与预算维度对齐

若实际科目与预算科目名称不一致，执行语义匹配并请用户确认。

### Step 4. 建立对比框架

逐项建立预算-实际对照：

```
科目 | 预算数 | 实际数 | 差异额 | 差异率 | 执行率 | 累计预算 | 累计实际 | 累计差异
─────────────────────────────────────────────────────────────────────────────
收入  | 1000  | 950   | -50   | -5.0% | 95.0% | 3000   | 2850   | -150
成本  | 600   | 650   | +50   | +8.3% | 108.3%| 1800   | 1950   | +150
费用  | 200   | 220   | +20   | +10.0%| 110.0%| 600    | 640    | +40
利润  | 200   | 80    | -120  | -60.0%| 40.0% | 600    | 260    | -340
```

计算公式：
- **差异额** = 实际数 - 预算数
- **差异率** = 差异额 / 预算数 × 100%
- **执行率** = 实际数 / 预算数 × 100%

收入类：执行率 < 100% 为不利差异（标记红色）
支出类：执行率 > 100% 为不利差异（标记红色）

### Step 5. 识别异常变动

按设定阈值（默认 ±10%）识别异常项，分级标注：

| 级别 | 差异率 | 标记 |
|------|--------|------|
| 正常 | |差异率| ≤ 10% | 绿色 |
| 关注 | 10% < |差异率| ≤ 20% | 黄色 |
| 预警 | 20% < |差异率| ≤ 50% | 橙色 |
| 严重 | |差异率| > 50% | 红色 |

异常识别维度：
1. **单期差异**：本期实际 vs 本期预算
2. **累计差异**：累计实际 vs 累计预算
3. **趋势差异**：连续多月超预算的科目
4. **结构差异**：实际构成与预算构成偏离

### Step 6. 分析差异原因

对异常项目逐一分析差异原因，按以下框架：

**收入差异原因**：
- 量差：销量/业务量未达预期
- 价差：单价/费率变动
- 结构差：产品/业务结构变化
- 时间差：收入确认时间差异

**成本/费用差异原因**：
- 量差：消耗量/发生频次超预期
- 价差：采购单价/费率上涨
- 效率差：单位产出消耗增加
- 新增项：预算未覆盖的新增支出
- 时间差：费用确认时间提前/延后

**资本支出差异原因**：
- 进度差：项目推进速度与预算不一致
- 规模差：投资规模变化
- 价格差：设备/工程单价变动

分析时结合用户提供的数据上下文推断原因，无法确定时列出可能原因请用户确认。

### Step 7. 生成报告

输出文件结构（Excel多sheet）：

| Sheet名 | 内容 |
|---------|------|
| 预算执行总表 | 预算vs实际汇总对比 |
| 分项明细 | 逐科目明细对比，含差异额/率/执行率 |
| 异常项目清单 | 超阈值异常项汇总及原因分析 |
| 趋势分析 | 各科目月度/季度执行趋势图表 |
| 原因分析 | 各异常项差异原因详细说明 |
| 改善建议 | 基于差异分析的管理建议 |

Word/PDF输出时，按"执行概况 → 分项明细 → 异常预警 → 原因分析 → 改善建议"结构编排。

### Step 8. 生成改善建议

基于差异分析，输出可操作的建议：
1. **超预算项**：建议控制措施（如费用审批收紧、采购比价等）
2. **预算不足项**：建议预算调整（如追加收入预算或削减其他支出）
3. **持续偏差项**：建议重新评估预算合理性
4. **结构优化**：资源配置优化建议

## 注意事项

- 预算科目与实际科目必须完全对应，无法对应时标注为"未匹配"
- 收入/利润类超预算为正向偏差，支出类超预算为负向偏差，标记方向不可混淆
- 累计执行率需注意：年度预算分月执行时，进度偏差需结合时间进度判断
- 零预算项有实际发生额时单独标注为"预算外支出"
- 金额单位统一，百分比保留2位小数
